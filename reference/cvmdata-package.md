# cvmdata: Tidy Access to Brazilian CVM Open Data

Provides a tidy API to the open data published by the Brazilian
Securities and Exchange Commission ('CVM' - Comissao de Valores
Mobiliarios). The package's first release covers core
publicly-traded-company datasets: 'cad' (company registry), 'itr'
(quarterly financial statements), 'dfp' (annual financial statements)
and 'fre' (reference form, including ESG/governance tables). Column
names, table names, categorical values and free text are preserved in
Portuguese as published by 'CVM'; function names, arguments and metadata
attributes are in English following the rOpenSci and tidyverse
conventions. Future releases will expand coverage to investment funds
and other regulated entity classes.
